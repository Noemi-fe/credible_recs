- Test first: write or extend the test (including the edge cases in the End-state tree tab), watch it fail, then make it pass.

- Hill-climb: run eval/run_eval.py, fix the weakest metric, re-run. Keep a change only if metrics improve with no regression. Log every run in eval/RUNS.md.

- Reddit data comes only from the hand-collected gold set, the Parse reddit.com API (engine/parse_reddit.py) and the Arctic Shift archive API. Since 9 Oct 2026 (Noemi, instead of paying for Parse) threads may be READ from Arctic Shift's archive and stored, because every archive-read thread is checked live through Parse: answers only quote threads checked live within 14 days, every other archive thread is checked monthly, and archive text not checked within about 37 days is removed (engine/library.py check-live). An archive keeps comments people later deleted; the live checks are what keep the deletion rule. Also since 9 Oct 2026 (Noemi approved Reddit's embed service): before an answer shows a quote, the comment is read through Reddit's official embed page (embed.reddit.com, what oEmbed's widget loads), one comment at a time, only for quotes answers show or would show, read as the answer is written or, since 13 Oct 2026, the day before by the daily pre-check; a quote needs a passing check from the last 48 hours; a deleted, removed or edited comment (quote no longer found) is never shown (engine/live_check.py). Bright Data (Noemi's account, free tier: 5,000 records a month, key in .env) reads threads as Reddit shows them now (engine/bright_data.py); it returns top-level comments and their direct replies only, so a reply missing from its answer is never taken as deleted. Since 10 Oct 2026 (Noemi asked for a Bright Data tool "to not get stuck with parse and everything else") it is a full source: `library add` finds threads with Reddit's own search through it and reads them (engine.sources.BrightDataSource), the default reader "auto" tries Arctic Shift first and turns to Bright Data when it fails (remembered for 30 minutes), `library refresh` reads through it by default, and reads go in batches of 20 threads (two jobs per batch). Bright Data has no Reddit profile scraper: writer profiles still come only from Arctic Shift. Not built, on purpose: our own scraper of reddit.com through Bright Data's unblocker (it would get around Reddit's anti-scraping protections, which Reddit is suing over; Noemi's call). Both are third-party services, not Reddit's official API; Noemi chose Parse on 7 Oct 2026 after Reddit refused API access, and Arctic Shift the same day. No other scraping.
